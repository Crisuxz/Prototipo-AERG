# Frontend

React + TypeScript + Vite + Tailwind CSS v4 + React Router + Axios. Ver `docs/PLAN_MAESTRO.md` para la arquitectura completa.

## Arranque en desarrollo

```bash
npm install
npm run dev
```

La app corre por defecto en `http://localhost:5173` y consume la API en `/api` (configurable con `VITE_API_BASE_URL`).
